# Nette Beckers | Interactive Creative Developer CV

An interactive portfolio and CV for Nette Beckers, a Belgian creative developer who builds playful, immersive digital experiences. Explore her work through a desktop-inspired interface, complete with project windows, a terminal, and a playable Tetris game.

## Open the portfolio

This project is a standalone HTML page with no build step or dependencies to install. Open [`nette.html`](nette.html) in a browser, or serve the repository with any static file server.

## Explore

- **About**: Nette's approach, interests, and technical toolkit
- **Projects**: immersive experiences, a data-awareness installation, and client work
- **CV**: education, professional experience, and volunteering
- **Terminal**: an interactive command-line-style introduction
- **Tetris**: a playable version of Nette's favorite game
- **Contact**: ways to get in touch about creative developer opportunities

## Built with

HTML, CSS, and vanilla JavaScript. The interface and interactions are contained in `nette.html`; Google Fonts provides the Syne and Space Mono typefaces.
